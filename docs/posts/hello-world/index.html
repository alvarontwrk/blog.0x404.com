The first post on a new minimalist blog.

Welcome to the blog.

This setup is intentionally small:

  • Write posts in Markdown
  • Add front matter with a title and date
  • Build to static HTML with Eleventy

You can create another post by adding a new Markdown file inside src/posts.

A small note

The theme uses #4169e1 as the main accent color, with plenty of whitespace and minimal decoration.
